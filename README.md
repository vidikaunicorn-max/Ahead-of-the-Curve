# Ahead of the Curve

A precision forecaster for the local mass density ρ₀, based on the research paper *Local mass density from Hipparcos K giants: a vertical Jeans–Poisson analysis with a mixture of isothermal components* by Vidika Mirpuri.

Open `index.html` in any browser to use it. Pages: Forecaster, Method, About, Contact.
